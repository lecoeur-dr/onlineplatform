# OnlineFlatform 멀티 학교 · Deskterior · 3차 기능 설계

## 0. 결론

| 요청 | 반영 |
|---|---|
| 이름 변경 | **OnlineFlatform** (`public/js/modules.js`의 `APP_NAME` 한 곳에서 바꿈) |
| 상단 2탭 | 🏫 **OnlineFlatform**(학교 업무) / 🪴 **Deskterior**(내 학급·수업) — 탭마다 왼쪽 메뉴가 바뀜 |
| 왼쪽 메뉴 접기 | 큰 항목 옆 ▾ 로 접고 펴기, 기기에 기억 |
| 로그인 | 구글 계정이면 누구나 로그인 → 학교 자료는 **학교 관리자 승인** 뒤 열림 |
| 여러 학교 | 학교마다 데이터·설정·구성원·권한이 분리. 한 사람이 여러 학교에 속할 수 있음(상단에서 학교 전환) |
| 3차 | 휴대폰 알림(웹 푸시)+알림함, 조례·종례 전달사항, 개인 할 일(반복) |

## 1. 사용자·권한 구조

```
플랫폼 운영자 (ADMIN_EMAILS, 1명~)
 └─ 새 학교 개설 승인 / 학교 사용 중지 (학교 자료는 볼 수 없음)
학교 (schools)
 ├─ 학교 관리자 (members.role=admin) — 가입 승인, 초대 링크, 설정, 가져오기
 ├─ 교직원 (staff) — 입력·수정
 ├─ 열람 (viewer) — 보기만
 └─ 승인대기 (pending) — 학교 자료 못 봄
개인 (모든 로그인 사용자)
 └─ Deskterior — 본인만 보는 개인 공간 (학교 가입 없이 사용 가능)
마켓 — 모든 학교 선생님이 함께 보는 자료 공유
```

### 학교에 들어가는 3가지 길

| 방법 | 흐름 | 승인 |
|---|---|---|
| 초대 링크 | 관리자가 `…/#/join/코드` 링크·QR 공유 → 로그인 → 자동 가입 요청 | 학교 관리자 |
| 학교 찾기 | 학교 이름 검색 → 가입 요청 | 학교 관리자 |
| 미리 등록 | 관리자가 이메일을 미리 등록 | 필요 없음(첫 로그인부터 사용) |
| 새 학교 개설 | 나이스 학교 검색으로 선택 → 개설 신청 → 신청자 = 그 학교 관리자 | 플랫폼 운영자 |

- 같은 나이스 학교 코드로 이미 개설된 학교는 중복 개설을 막고 가입 요청으로 안내
- 가입 요청·승인, 학교 개설·승인 때 알림함/휴대폰 알림 발송

## 2. 데이터 구조 (마이그레이션 0003)

| 표 | 내용 |
|---|---|
| `schools` | 학교 (상태: active/pending/closed, 초대 코드, 나이스 코드) |
| `members` | 학교별 구성원·권한·학교 안 이름·부서 (PK: 학교+이메일) |
| `school_settings` | 학교별 설정 (학년도, 목록, 나이스) |
| `records.school_id` | 학교 기록 |
| `records.owner` | 개인 기록(Deskterior)·마켓 작성자 |
| `inbox` | 알림함 |
| `push_subs` | 휴대폰 알림 구독 기기 |

- 기존 서부초 데이터는 모두 첫 학교 `s1`로 이동, 기존 사용자 권한도 그대로 `members`로 이동
- 모든 서버 조회에 `school_id`(학교) 또는 `owner`(개인) 조건이 붙음 → 다른 학교·다른 사람 자료 접근 불가 (로컬 시험으로 확인: 다른 학교 머리글로 요청 시 403)

## 3. Deskterior (tdesk 벤치마킹)

> tdesk.web.app은 작업 환경에서 접속이 차단되어 화면을 직접 보지 못했습니다. 요청하신 5개 메뉴(학급/수업/평가/기록/마켓) 이름과 일반적인 교사용 학급 관리 도구 구성을 바탕으로 설계했습니다. **[확인 필요]** tdesk 화면 캡처를 주시면 세부 기능을 더 맞추겠습니다.

| 메뉴 | 기능 | 비고 |
|---|---|---|
| 내 책상(홈) | 할 일, 오늘 전달사항(학교), 오늘 내 수업, 다음 진도, 이번 주 누가기록 현황 | |
| 학급 | 학생 명단(여러 명 붙여넣기), 자리 배치(랜덤·바꾸기·인쇄), 1인 1역(랜덤 배정), 뽑기(중복 없이)·모둠 나누기·타이머 | |
| 수업 | 오늘 수업, 내 시간표(학교 시간표에서 가져오기), 진도표(과목별·완료 체크) | |
| 평가 | 평가 계획 → 학생별 잘함/보통/노력 요함 + 관찰 메모, CSV 저장 | |
| 기록 | 누가기록(학생별 타임라인, 기록 없는 학생 표시), 할 일(반복) | 내용 암호화 |
| 마켓 | 모든 학교 선생님이 자료 링크 공유, 분류·검색·좋아요, 내 자료만 수정 | 링크 공유 방식 |

### 개인정보 보호
- Deskterior 기록은 **본인만** 조회 (서버가 owner로 거름)
- 학생 특이사항·누가기록 내용은 **AES-GCM 암호화 저장** (DATA_KEY)
- 화면에 "필요한 만큼만 기록" 안내. 주민번호·연락처 칸은 만들지 않음
- 마켓에는 학생 개인정보가 담긴 자료를 올리지 말라는 안내 표시

## 4. 3차 기능

| 항목 | 구현 |
|---|---|
| 휴대폰 알림 | 웹 푸시(VAPID). 내용 없는 신호만 보내고, 기기가 알림함에서 내용을 가져와 표시 → 암호화 부담 없음. 아이폰은 "홈 화면에 추가"한 앱에서만(iOS 16.4+) |
| 알림 대상 | 보결 배정→보결 교사, 담당 배정→담당자, 전체 공지·전달사항→학교 전체, 수합→대상자, 가입 요청→학교 관리자, 승인→본인 |
| 알림함 | 상단 🔔 (휴대폰 알림을 안 켜도 확인 가능) |
| 조례·종례 전달사항 | 공지·업무 → 전달사항. 날짜별 모음, "크게 보기"(교실 화면용), 홈·내 책상에 오늘 전달사항 |
| 개인 할 일 | Deskterior → 기록 → 할 일. 반복(매일·평일·매주·매월) 체크 시 다음 날짜로 |

## 5. 한계·주의
- 무료 요금제: 한 번에 보내는 휴대폰 알림은 최대 40대(하위 요청 한도). 학교 규모가 크면 유료 전환 또는 알림 대상 축소 필요 **[확인 필요: 실제 사용량]**
- 매일 새벽 나이스 자동 동기화는 학교 20곳까지 처리 (그 이상은 분할 필요)
- 구글 로그인을 "누구나"로 하려면 Google Cloud의 OAuth 앱을 **프로덕션(게시)** 상태로 바꿔야 함 → `02_배포_가이드.md` 참고

## 6. Deskterior v2 — 실사용 기능 (2026-10-01)

벤치마킹 근거: tdesk(메뉴 구성 — 사이트 직접 열람 불가 [확인 필요]), 학급다이어리2(출결 통계·체크리스트·'이번주' 주간 보기), Classendo(즉석 평가·특기사항 입력)

| 메뉴 | 추가 기능 |
|---|---|
| 내 책상 | 오늘 출결·알림장·할 일·오늘 수업·전달사항·체크리스트·다음 진도·누가기록 현황, 오늘 생일, 빠른 실행 |
| 학급 | **학생 카드**(출결·칭찬·평가·체크·누가기록·상담을 한 학생 화면에), **출결**(날짜별 원클릭, 사유·증빙, 월별 통계·CSV·증빙 미제출 목록), **체크리스트**(학생 칩 체크, 미완료 명단 복사), **칭찬 점수**(타일 한 번 누르면 +1), 명단(연락처·알레르기·방과후 — 암호화) |
| 수업 | **이번 주**(요일별 수업·진도·출결·할 일·알림장·학교 일정·전달사항), **알림장**(번호 자동, 크게 보기, 복사), **주간학습안내**(내 시간표로 과목 채우기, 인쇄), 진도·**시수 집계** |
| 평가 | **즉석 평가**(학생 타일 누를 때마다 단계 순환·자동 저장), **학생별 결과**(◎○△ 표), **특기사항**(학생별 입력·자동 저장·글자/바이트 계산·누가기록/평가 메모 참고·CSV) |
| 기록 | 누가기록, **상담 기록**(대상·방법·주제·후속 조치, 암호화), 할 일 |

화면: 왼쪽 메뉴는 기본 숨김(☰로 열고 📌로 고정), 머리글 아래 알약형 영역 바, 카드·버튼·표 전반 리디자인(`public/css/theme.css`).

## 7. 새 학기 자료 가져오기 (2026-10-01)

학교 관리 → 🪄 새 학기 가져오기. 파일은 브라우저 안에서만 읽음(서버 전송 없음).

| 입력 | 지원 |
|---|---|
| 한글 | **HWPX** (표·병합 셀·문단). 예전 `.hwp`는 HWPX로 저장하거나 표 복사 → 붙여넣기 |
| 엑셀 | XLSX(병합 셀 채움), CSV |
| 붙여넣기 | 한글·엑셀 표 복사(탭 구분) 또는 줄글 |

| 종류 | 인식 규칙 | 저장 |
|---|---|---|
| 학사일정 | `월 | 일 | 요일 | 행사` 표(월 병합), 달력형 칸(`2 입학식`), 줄글(`3. 2.(월)`, `3월 2일`, `2026.3.2`, `7월 24일 ~ 8월 18일`) · 방학·공휴일 자동 분류 · 1~2월은 다음 해 | 학사일정 (추가 또는 바꾸기, 나이스 일정 유지) |
| 업무분장 | 머리글(성명·직위·부서·담임·담당 업무·내선 등)로 칸 찾기, 부서 병합 이어받기, `6학년 1반`→`6-1` | 학교 정보 → 업무분장 + 부서·학급 목록 + 교직원 드롭다운(가입 전 이름 포함) |

자동 점검(체험·로그인 모드): 모든 입력 폼의 목록 칸, 안쪽 링크 52~53개 화면 — 오류·튕김 없음.
