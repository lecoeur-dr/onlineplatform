# 온라인 교무실 — 화면 재구조화 설계 (v2)

## 0. 결론

| 문제 (v1) | 원인 | v2 해결 |
|---|---|---|
| 시트를 메뉴로 나열만 함 → 한눈에 안 보임 | 시트 1개 = 메뉴 1개 | **업무 영역 6개로 묶고**, 각 영역에 **전체 보기 + 세부 탭** |
| 달력이 한 달씩만 보임 | 월 단위 화면만 있음 | **연속 스크롤(세로)**, 월별 보기(←/→·스와이프), 목록 |
| 행사 종류가 구분 안 됨 | 분류가 '행사' 위주 | **색 분류 10종** + 범례 눌러 켜고 끄기 |
| 특별수업·출장·동료장학이 달력에 따로 놂 | 입력 표와 달력이 분리 | 같은 **달력 부품**을 영역마다 재사용: 입력하면 바로 달력에 표시 |
| 월별 안내와 안내사항이 따로 있음 | 시트 구조 그대로 | **공지** 하나로 통합, '전체 공지' 체크 시 달력 월 머리·홈에 고정 |
| 회의록이 줄줄이 나열 | 행 단위 목록 | **같은 날·같은 회의**(예: 월례회의) 묶음 카드 |
| 물품·공모·예산이 따로 | 서로 연결 없음 | **예산 현황 대시보드**: 예산·공모 금액 대비 물품 신청액 |

원칙 3가지 (사용자 요구): **① 한눈에 전체 ② 영역·구분별 보기 ③ 바로 입력·수정**

## 1. 메뉴 구조 (왼쪽)

| 영역 | 전체 보기 (영역 첫 화면) | 세부 탭 |
|---|---|---|
| 🏠 홈 | 오늘·이번 주 일정, 고정 공지, 오늘 특별수업·출장, 예산 요약, 재논의 안건 | - |
| 📅 학사일정 | **통합 달력** (학사일정+특별수업+출장+동료장학, 색 구분) | 일정 목록 · 출장 |
| 🕘 수업 | 수업 달력 (특별수업+동료장학+학급수업) + 오늘 시간표 | 시간표 · 특별수업 · 동료장학 |
| 📢 공지·회의 | 고정 공지 + 이번 달 공지 + 최근 회의 | 공지 · 회의록 |
| 💰 예산·물품 | **예산 사용 현황** (재원별 배정·신청·수령·잔액) | 물품 신청 · 예산 · 공모사업 · 공모 안내 |
| 🗂 학교 정보 | 바로가기 카드 + 계정·비밀번호 (분류별) | 계정·바로가기 · 내선번호 · 위임전결 · 자유 표 |
| ⚙️ 관리자 | (관리자만) | 사용자 · 설정 · 가져오기 · 연도 복사 · 변경 기록 · 백업 |

- 주소 형식: `#/영역/탭` (예: `#/class/programs`) → 즐겨찾기·공유 가능
- 휴대폰: 메뉴는 ☰ 로 열고, 세부 탭은 화면 위 가로 탭

## 2. 색 분류 (학사일정 달력)

| 분류 | 색 | 예 |
|---|---|---|
| 전체행사 | 파랑 | 운동회, 입학식, 체험학습 |
| 학급수업 | 초록 | "(1~2교시 3-1)"처럼 특정 학급 대상 수업·교육 |
| 특별수업 | 보라 | SW·AI, 국악·무용·연극, 음악줄넘기 |
| 동료장학 | 분홍 | 수업공개 (동료장학 입력 시 자동) |
| 회의 | 청록 | 월례회의, 협의회 |
| 연수 | 주황 | 교직원 연수 |
| 출장 | 갈색 | 출장 입력 시 자동 |
| 대회출전 | 남색 | 수영대회, 육상대회 |
| 휴일·방학 | 빨강 | 공휴일, 재량휴업, 방학 (수업일수 계산에서 제외) |
| 기타 | 회색 | - |

- 범례를 누르면 해당 분류만 끄고 켤 수 있음 (선택은 브라우저에 기억)
- 가져오기 시 제목으로 자동 분류: `대회` → 대회출전, `n-n` + `교시` → 학급수업, 공휴일 이름 → 휴일 등

## 3. 달력 부품 (한 번 만들어 여러 곳에 사용)

| 보기 | 설명 |
|---|---|
| 연속 | 1월 ~ 다음해 2월(14개월)을 **주 단위로 세로로 이어서** 표시, 열면 오늘 주로 이동, 월이 바뀌는 곳에 월 이름 + 그 달 고정 공지 |
| 월별 | 한 달 표. ←/→ 버튼·키보드·좌우 스와이프로 이동 |
| 목록 | 날짜순 표 (인쇄·검토용) |

- 어디서든 날짜 칸의 **+** 로 그 영역의 기록을 바로 입력 (학사일정 달력 → 일정, 특별수업 달력 → 특별수업)
- 사용 위치: 학사일정 전체, 수업 전체, 특별수업 달력, 출장 달력, 동료장학 달력

## 4. 데이터 규격 변경

| 메뉴 | 변경 |
|---|---|
| 학사일정 | 분류 10종으로 교체, `대상`(학년·학급) 칸 추가 |
| 공지 (안내사항+월별 안내 통합) | `제목`, `분류`(월별 안내/부서 안내/일반), `해당 월`, `전체 공지`(고정), `수업일수` 추가 |
| 회의록 | `회의명`(전체회의·월례회의·부장회의 등) 추가 → 날짜+회의명으로 묶음 |
| 시간표 | 종류: **학급 · 전담 · 특별실 · 외부강의 · 기타**, 학급은 1학년부터 순서대로 |
| 동료장학 | `공개일`(날짜)·`교시` 분리 → 달력 표시 |
| 바로가기 | `분류` 추가 → 계정·비밀번호와 한 화면 |
| 물품 신청 | `예산 구분`을 **예산·공모사업 목록에서 선택** → 재원별 사용 현황 자동 계산 |

## 5. 예산 사용 현황 (예산·물품 첫 화면)

| 재원 | 배정액 | 신청액 | 수령 완료 | 잔액 | 진행 막대 |
|---|---|---|---|---|---|
| 예산 항목 · 공모사업마다 한 줄 | 예산/공모 금액 | 물품 신청 금액 합 | 수령 체크된 금액 합 | 배정 − 신청 | 신청/배정 % |

- 물품 신청 목록은 재원별로 묶어서 보기 가능, 신청자별 합계 표시

## 6. 참고한 구성

| 출처 | 가져온 아이디어 |
|---|---|
| 기존 구글 시트 | 월별 달력 + 월 머리 '교육과정 주요 안내', 부서별 안내 칸, 동료장학 참관 체크 |
| 노션형 온라인 교무실 템플릿 | 영역별 묶음 사이드바, 한 데이터를 여러 보기(달력·표·보드)로, 태그 색 구분 |
| 구글 캘린더 | 연속 스크롤, 분류 켜고 끄기, 날짜 칸에서 바로 추가 |

## 7. 이관

- 가져오기 규칙을 v2 규격에 맞게 수정 → **관리자 → 엑셀 가져오기**에서 같은 파일을 **"바꾸기"로 한 번 더** 가져오면 새 구조로 정리됨
- 이전 '월별 안내' 기록은 공지로 합쳐짐
