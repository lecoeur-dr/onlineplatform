# 온라인 교무실 — 벤치마킹 비교 분석

> ⚠️ 두 사이트는 직접 열람하지 못했습니다. 아래는 공개 자료 기준이며, 화면 구성·세부 동작은 [확인 필요]입니다.
> tdesk.web.app 이 검색에서 나온 '선생님의 책상'(제작: 보라쌤)과 같은 서비스인지 [확인 필요].

## 0. 결론

| 구분 | 선생님의 책상 (tdesk) | TeacherDesk2 (kimju.kr/td2) | 우리 온라인 교무실 |
|---|---|---|---|
| 성격 | 중·고 **교사 개인·학급 업무** 웹 도구 | 교사 **개인 PC 바탕화면 위젯** (윈도우 프로그램) | **학교 공동 교무실** (함께 입력·관리) |
| 강점 | 학교만 고르면 급식·학사일정 자동, 수합·예약 링크, AI 세특 초안 | 한 화면 위젯, 시간표 자동(컴시간·나이스), 수업 전 알림, 폰 연동 | 규격화된 공동 데이터, 권한·변경 기록, 예산 현황, 동료장학, 시트 이관 |
| 약점 (우리 대비) | 학교 공동 운영 기능 제한적 [확인 필요] | 교무실 정보는 **구글 시트에서 받아 보여주기만** 함 | **자동 연동 없음**(전부 직접 입력), 복무·보결·수합 기능 없음 |

**핵심 시사점:** 두 도구 모두 **"직접 입력은 줄이고(자동 연동), 오늘 할 일을 한 화면에"**가 공통 철학입니다. 우리 시스템은 '학교 공동 관리' 쪽은 앞서 있지만, **나이스 자동 연동**과 **교무실 일상 업무(복무·보결·서류 수합)**가 빠져 있습니다.

## 1. 선생님의 책상 (tdesk) — 공개 소개 기준

| 영역 | 기능 |
|---|---|
| 시작 | 학교 선택만 하면 **급식·학사일정 자동** 표시 |
| 달력 | 학사일정·마감·급식을 한눈에 + **한 줄 메모** |
| 업무 | **제출·수합 현황**, 공유 자료실 |
| 학급 | 연락처 검색, 학생 개별 기록 |
| 링크 하나로 | **시험 감독표**, **상담 예약** |
| AI | 한 줄 메모 → **세특(생기부) 초안**, 수행평가 PDF·빠른 채점 |
| 계정 | 학교·개인 구글 계정, **첫 가입자가 학교 관리자**(운영자 승인) |

## 2. TeacherDesk2 — 릴리스 노트 기준

| 영역 | 기능 |
|---|---|
| 형태 | 윈도우 바탕화면 위젯 (무료, Electron) + 폰 페이지(m.kimju.kr/td2, **QR로 연결**) |
| 위젯 | 시계·날씨·급식·주간 시간표·학사일정·할 일·D-Day·메모·진도표·AI 도우미·생기부 도우미 |
| 시간표 | **컴시간 알리미·나이스에서 자동**, 칸 직접 수정 가능(수정 칸 표시), **휴일이면 시간표 칸 자동 비움** |
| 온라인 교무실 위젯 | 교무부장이 **학교 구글 시트 하나**에 **공지·출장·조퇴·보결·행사** 입력 → **1분 안에** 교사 화면에 **날짜별 게시판** / [오늘][주간][전체] / 지난 항목 자동 접힘 / 부서별 색 |
| 수업 지원 | **수업 전 알림**(큰 팝업·음성), 조례·종례 문구 정리(AI, 없는 사실 추가 안 함), 지난 시간 진도 표시 |
| 할 일 | 매일·매주 **반복 할 일**이 달력에 미리 표시 |
| 서류 | **서류 제출 체크**(결석계·증빙·동의서), 미제출 건수 표시 |

## 5. 배포 버전(②앱스크립트 ③스프레드시트)에 주는 시사점

- TD2의 **"학교 구글 시트 하나 + 공유 링크"** 방식은 ③ 스프레드시트 버전과 같은 방향 → 시트 구조를 TD2 온라인 교무실 위젯과 호환되게 맞추면 두 도구를 함께 쓸 수 있음 [확인 필요: TD2 시트 형식]
- tdesk의 **"첫 가입자가 학교 관리자"** 방식은 여러 학교 공유 시 온보딩 참고
